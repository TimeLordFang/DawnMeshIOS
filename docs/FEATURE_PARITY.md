# iOS 与 Android 1.1.0 功能对标

“实现”指源码路径已接通，不代表真机/发布签名验收通过。具体检查见 VALIDATION.md。

| 功能 | iOS 实现与边界 |
| --- | --- |
| 多服务器、公网房 25 人 | 复用相同 API、凭据、LiveKit，容量由服务器控制 |
| 语音与聊天 E2EE、四位码 | 复用 Android 密码学，浏览器协议样本回归 |
| 房主禁麦/移交/改名/断线保留 | 复用服务器管理策略和页面 |
| 公网三档音质、PTT/自动发言 | 复用音频配置和 SDK 轨道策略 |
| Wi-Fi 16 人、PAKE | 普通房支持苹果点对点 Wi-Fi；保留同网 TCP/Opus、手动入房/单播发现 |
| 附近自动发现 | 普通 Wi-Fi 房启用苹果点对点 Bonjour；安卓 UDP 自动广播需 Apple 组播权限 |
| Android Wi-Fi Direct 自动建群、连群 | 无跨平台直连；iOS 间使用苹果点对点 Wi-Fi，混合设备使用同网/热点 |
| 蓝牙 6 人 | iOS 可建房/加入；GATT 元数据发现 iOS 房主，旧安卓厂商广播兼容；混合六人待真机验收 |
| 融合 16 人、离线/公网中继 | 复用签名名单、能力票据、WebSocket、去重、恢复 |
| 融合 Wi-Fi Direct 自组网 | 暂缓；LAN/热点和公网路径保留 |
| 聊天、照片、撤回/同步 | 复用逻辑并声明 iOS 相册、相机权限 |
| 昵称、设备短码、成员头像 | 复用；iOS 使用 UserDefaults 与 Keychain |
| 音频输入选择、扬声器/听筒 | AVAudioSession 路由，实际组合需真机验收 |
| 标准/强力降噪 | 近场 16kHz Opus 前处理，公网 WebRTC 后处理，复用 RNNoise |
| 多人播放/PLC | 每人独立 Opus 解码/抖动缓冲，20ms PCM 饱和混音 |
| 蓝牙耳机共存降码率 | 原生路由可选；射频稳定性、与 BLE 并发的自动调优待真机测量 |
| 最长 30 分钟重连 | 共享 Dart 重连策略；iOS 调度/后台限制影响实际执行 |
| 锁屏继续收发 | 声明 audio 后台模式；持续音频与音频中断恢复代码已接入，待真机验证 |
| 安卓锁屏对讲面板/前台常驻通知 | 暂缓 Apple PushToTalk 等系统适配，不伪造安卓通知能力 |
| 本机日志、筛选、复制、诊断 | 共享 Dart 日志；Swift 提供系统/音频快照，无全系统日志权限 |
| 音频调参 | 抖动预缓冲/容量/PLC/码率可应用；Android AudioTrack 与 flush 参数对 iOS 不适用 |
| 入退房/断线播报 | AVSpeechSynthesizer |
| 中英、昼夜主题、页面转场 | 继承现有 Flutter 界面 |
| 安装与更新 | iOS 独立 Releases；正式安装需要 Apple 签名 |

网页参与范围沿用服务器当前能力：普通公网房可以三端同房；近场和融合房不能宣称网页参与。
