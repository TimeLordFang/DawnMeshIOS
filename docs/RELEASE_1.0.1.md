# DawnMesh iOS 1.0.1（build 2）

修复共享会话安全状态和原生蓝牙发现缓存，面向开发与内部测试。

- 同一密钥重连保留防重放窗口和发送计数；换密钥才创建新的加密会话。
- BLE 扫描缓存按时效和容量淘汰，保护连接及重连目标；重复发现限频并继续刷新房间存活时间，缓存音频调参值。
- 增加应用隐私清单和中英文权限说明，移除未使用的蓝牙 peripheral 后台声明。
- 同步无障碍 PTT、共享音频生命周期处理和未使用代码清理，保留 iOS 原生能力差异。
- Pod 安装在已有锁文件时使用 deployment 模式，首次生成锁文件时明确提示。

已通过 298 项 Dart 回归（包含真实 Go 融合中继）、静态分析、原生 Opus/RNNoise、Swift 协议及 BLE 缓存测试，以及 Swift 语法和 plist/工程资源检查。
本机没有完整 Xcode/CocoaPods，本版尚未验证完整 iOS 应用构建，也尚未生成真实 Podfile.lock；需在对应环境生成并提交。真机蓝牙、锁屏、VoiceOver、签名与商店申报另行验收。
配套 Android 1.1.2、Server/Web 0.3.2，现有协议不变。
