# DawnMesh iOS 1.0.4

版本：1.0.4+5；配套 Android 1.1.5，Server/Web 0.3.3 无需升级。

- 普通页面和公网房使用原生交互侧滑；本地房间沿用舞台转场并随手势推进，取消时回弹。聊天、成员、设置、诊断和高级调优弹层补齐侧滑动画。
- 返回时保留房间、通话和聊天；键盘打开时优先收起键盘，完成返回时释放按住说话状态。
- 修复邀请码弹窗打开键盘时重建首页、导致确认后无法进入 Wi-Fi、蓝牙或融合房的问题。手势启用状态切换保持页面和待完成回调。
- 即使安卓主广播只含通道和人数，仍继续读取完整 GATT 房名；完整名称不会被后续短广播覆盖。入房采用最新名称，缺名时依据已认证房主补全标题。

验证：iOS Flutter 316 项、Swift 190 项检查通过；安卓 Flutter 297 项、JVM 41 项及 Lint 通过。两端各 1 项真实 Go 中继集成测试因未配置测试服务器按既有配置跳过。静态检查与两端 Release 构建通过，详见 [验证记录](VALIDATION_2026-10-17.md)。

完整安卓房名补读需配套 Android 1.1.5；旧安卓广播仍兼容，入房后可用房主信息补全缺失标题。建议双方保持前台复测；实际无线发现、多人语音和锁屏行为仍待真机验收。

GitHub Release 提供未签名 App ZIP 及 SHA-256，不能直接安装到 iPhone。普通 Apple 账号测试请运行 `./scripts/prepare-ios.sh`，随后在 Xcode 选择自己的 Team 和 iPhone，按 ⌘R 构建安装。
