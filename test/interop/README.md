# Android Opus fixture

`android-opus-16k-20ms.bin` was generated by `AndroidOpusInterop.java` using Maven
`io.github.jaredmdobson:concentus:1.0.2`, matching DawnMesh Android's OpusCodec.
Input is 320 synthetic signed-16 samples: `sin(index * 0.13) * 12000`.
Configuration: 16000 Hz, mono, 20 ms, VoIP, 24 kbps, complexity 5, voice,
VBR + constrained VBR + DTX. This is a raw Opus packet, not a user recording.

`native/build/ios_codec_test test/interop/android-opus-16k-20ms.bin` decodes the
packet with the exact native bridge used by the iOS project. For a full
bidirectional check, use the commands in docs/INTEROPERABILITY.md.
